My software consists of:

```
1. Ubuntu server (with encryption enabled)
2. Docker
3. Netplan
4. Vlock
```

I use docker containers for my services, Netplan to assume a static IP to my laptop (this can also be done through your router's admin panel), and Vlock for physical security.

I don't use standard Ubuntu, instead I use the server version of it which has no graphical interface, since I don't need or want extra bloat.
